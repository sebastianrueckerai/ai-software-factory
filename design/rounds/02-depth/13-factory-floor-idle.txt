UI design mockup of the project screen of an AI software factory: the one screen a person uses to steer a software project that AI agents build. Desktop browser viewport, 16:9, flat, no browser chrome, no device frame, the screen fills the whole image.

Three elements in order of weight: the pulse (one sentence, what to know now) on top; the chat with the project agent as the main affordance, the place a person acts; the kanban board for the granular task state, quiet, scanned not read. Normal states whisper, exceptional states speak: the two items in Needs you are the loudest things on the screen, a done card is quiet.

A quiet moment of the same screen instead of the busy one. Status figures: "idle", "0 working", "0 need you", "€144.16 / €120.00" (over the cap, marked). Pulse, subdued, not prominent: "Factory is idle with no active work; spend of €144.16 has exceeded the monthly budget of €120.00." Board: "Needs you 0" empty, "Queued 2" with "#455 Live check: close (Stage 16, 3.4)" chip "backlog" "53 h 1 min in all" and buttons "Plan", "Ready", "Close", and "#178 Console: show the configuration version" chip "backlog" "347 h 40 min in all" with the same buttons; "Working 0" empty; "Verifying 0" empty; "Done 139" with quiet one-line entries "#490 README.md: extend the intro" done, "#616 Chat form: center the Send button" done, "#610 Fresh-context and aged-read acceptance tests" done, "#607 Live check 3.11: split pre-check" failed, "#608 Console polish: clamp board chip objectives" done, "#604 Members page" done, "#603 Session store: Postgres" done, "#599 Alerts: verdict buttons" closed. Chat: "Chat", "project agent · ai-software-factory-code", "New conversation", the line "Ask or tell the project agent. It reads, explains, moves, answers, steers and approves as you, through the console's own actions; it runs no code.", the message box and "Send". The empty columns must still look designed, not broken: the screen is calm and complete.

Direction "Factory floor": A factory floor. Stencil lettering for section heads, an andon lamp stack (green, amber, red) as the project state next to the status figures, cards as work orders on a clipboard with a small punched hole, one safety yellow used sparingly for Needs you, black and dark grey otherwise, 13 px sans. The chat as the foreman's radio panel across the bottom. Industrial, exact, not cartoonish. Dark theme.

Legible UI text with exact spelling, nothing invented. Made by a top product design studio. Not a template, not a slide deck, not a generic admin dashboard.
