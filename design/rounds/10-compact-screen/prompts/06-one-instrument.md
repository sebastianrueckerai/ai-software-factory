DESIGN DIRECTION 6 — ONE INSTRUMENT. The lamp language of the console's
notifications page takes over the whole screen, so every state answers in
the same grammar. The status strip's cells each gain their small square
lamp: state, working, waiting, need-you, spend. The open status detail is
one instrument row-set: the spend gauges, then a single readout line
("model gateway up · 2 runs waiting on the provider · GitHub
sf/ai-software-factory · configuration 4f2c9e1"), then the dependencies as
the notifications page would word them — a lamp before every service name,
lit green, ages on hover, down red and loud. The chat's window controls
become the same small square toggles the lamps use: an expand-glyph toggle
(chat across the whole screen) and a thread toggle, each with a lit state
when on, each with a tooltip; the border between board and chat carries a
lamp-styled grip on hover. The chat's floor is 24 rem with the threads
unfolded — the threads are the same instrument table (lamp · thread ·
last). The composer auto-grows to a third of the screen, then scrolls; no
button. Nothing on the screen introduces a second design language: bar,
strip, panel, chat head and thread table all answer with lamps, small caps
and mono figures. Every glyph carries a tooltip.
