DESIGN DIRECTION 1 — EDGE TABS. Every window state lives on an edge, as a
tab. The border between board and chat carries a slim vertical grip tab,
about 10 px wide and 64 px tall, centered vertically: three quiet grip dots
inside a hairline pill; on hover the pill brightens cyan and the cursor is
col-resize; a small tooltip reads "Drag to resize — double-click to reset".
The chat's own head keeps only its title; at the head's far right one quiet
icon button, a diagonal double arrow (expand glyph), tooltip "Chat across
the whole screen — the board hides". The chat's minimum width holds the
unfolded thread list comfortably: threads read as a compact mono table
(mark · thread · last) with the whole chat never narrower than about
24 rem. The composer has NO grow button: it grows with the typed message up
to about a third of the screen, then scrolls inside. The open status panel:
left, the two spend gauges (today, this month) exactly as decided; right,
one readout line — "model gateway up · 2 runs waiting on the provider" or
the waiting words absent when none, then "GitHub sf/ai-software-factory
· configuration 4f2c9e1"; below it the dependencies as one row of five
small lamps, each a 7 px dot with the service's name in small mono
(forgejo, object storage, postgres, provider api, temporal), all green,
ages on hover only; a down service turns its lamp red and its row unfolds
loud. Everything else on the screen stays the console's established
instrument look.
