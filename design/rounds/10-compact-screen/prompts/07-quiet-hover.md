not need at rest. The chat's head is only its title and the muted
"project agent · ai-software-factory-code"; its controls appear on hover as
a small quiet cluster at the head's right — an expand glyph, a thread
glyph, tooltips on each ("Chat across the whole screen — the board hides",

visible (quiet is not a trap). The border between board and chat is a bare
hairline that grows a grip on hover, tooltip "Drag to resize". The
composer grows with the message to a third of the screen, then scrolls; no
control. The chat's floor is 24 rem; the unfolded threads table is the
quietest thing on the screen — hairline rows, mono, one amber mark lamp
where a thread waits on you. The open status panel compresses to near
silence: the spend gauges; ONE line "model gateway up · GitHub
sf/ai-software-factory · configuration 4f2c9e1"; and the dependencies as
five green lamps with names, nothing else — no ages, no detail, all on
hover; a down service is the only thing allowed to be loud, red with its
age inline. The discipline: rest state shows state only; every detail is
one hover away; nothing blinks.
