## Global Constraints

- Hard-data ruling 2026-10-13: no LLM-computed metrics, one row per event, append-only facts, aggregates are queries computed at read, no stored daily summaries. `ci_runs` and `tasks.merge_commit` are collected facts, not aggregates.
- All windows and buckets in UTC. `from`/`to` are `YYYY-MM-DD` dates at UTC midnight, both included (window `[from, to+1d)`); the previous window is the same length immediately before. Default: `to` = today, `from` = `to − 27d`.
- Sparks are always the last 7 weekly buckets ending at `to` (seven half-open `[to−(7−i)·7d, to−(6−i)·7d)`, oldest first), independent of window length.
- A "card" is a task with `kind <> 'chat'` everywhere cards are counted (done, cycle, throughput, failure, diff, interventions denominator, per-card cost). Chat tasks keep their ledger and audit rows in the project's spend, tokens totals exclude them (`tokens/card` = cards' own calls), model mix includes every call of the project.
- Money EUR floats, durations integer ms in the report, tokens integers, ratios 0..1 in the report (the console formats `%`).
- The page follows the deck's words exactly (18 rows); values are real. Model mix lists real model aliases, not the deck's demo labels.
- The page measure is C29's 62 rem (not the prototype's 64). No new CSS tokens: dark and light from the existing `--*` vars. Minimal comments; no unrequested abstractions.
- Every task: `bash check` green (go vet, gofmt, gosec, `make test` = `scripts/pg-test.sh` + `go test -race -p 1 ./...`), one lowercase-one-liner commit with the `Co-Authored-By: Claude Code <noreply@anthropic.com>` trailer, pushed to `main`.
- Work happens in a worktree off `main` of the code repository. The round-11 build branch stays unmerged; nothing here rebases onto it.

## Review Focus

The failure modes the fixtures must exercise, each pinned by the named test:

1. **Empty cohorts:** a project with no data, or a figure whose window cohort is empty (rolls but no done cards) — counts render 0, medians/rates render `—` (`Has=false`), moves hide, no NaN from a zero denominator. → `TestMetricsEmptyProject`, `TestMetricsNoDoneCards`.
2. **Window before data / boundary windows:** previous window empty → `PrevHas=false` → no move; `from == to` (one day); 90-day window reaching before the project's first row. → `TestMetricsPreviousWindowEmpty`, `TestMetricsWindowEdges`.
3. **Honest sparks:** near-constant series widened so flat reads flat; all-equal series draws one level line (guard `lo=v−1, hi=v+1`); a series with one outlier does not collapse every other point onto one pixel. → `TestSparkWidensNearConstant`, `TestSparkAllEqual`, `TestSparkOutlier`.
4. **UTC bucket edges:** a roll at 23:59 UTC Sunday and one at 00:01 Monday land in different weekly buckets; the ledger's `day` date buckets by UTC day. → `TestMetricsWeekBuckets`.
5. **The seam is numbers:** `?format=json` returns named figures with numeric values and `weeks` arrays (no preformatted strings), and survives a fresh project. → `TestProjectMetricsJSON`.

### Task 3: The queries module — one function per figure

**Files:**

**Interfaces:**
- Produces (package `factoryd`, private functions; tests are in-package):

```go
type Figure struct {
    Value, Prev float64   // window value, previous-window value
    Has, PrevHas bool     // false = empty cohort: render —, hide the move
    Weeks [7]float64      // the spark: 7 weekly buckets ending at to
}
type RevertedRefiled struct { Reverted, Refiled float64; Prev [2]float64; Has bool; Weeks [7]float64 }
type MixShare struct { Alias string; Share float64 } // Share of tokens, 0..100
type DiffSize struct { Files, Insertions, Deletions float64; Prev [3]float64; Has, PrevHas bool; Weeks [7]float64 }
type ChatWork struct { Calls, Minutes float64; PrevCalls, PrevMinutes float64; Weeks [7]float64 }
type MetricsReport struct { // JSON tags snake_case: deploys, lead_time, card_cycle, throughput,
    // change_failure, reverted_refiled, time_to_restore, spend, per_card, tokens_per_card,
    // model_mix, interventions, escalations, human_blocked, review_acceptance,
    // self_deploys, diff_size, chat_tool_work, ci_duration — plus repository, from, to
    Deploys, LeadTime, CardCycle, Throughput, ChangeFailure, TimeToRestore Figure
    RevertedRefiled RevertedRefiled
    Spend, PerCard, TokensPerCard Figure
    ModelMix []MixShare
    Interventions, Escalations, HumanBlocked, ReviewAcceptance, SelfDeploys, CIDuration Figure
    DiffSize DiffSize
    ChatWork ChatWork
}
func (s *PGStore) Metrics(ctx context.Context, repository string, from, to time.Time) (MetricsReport, error)
```

- Consumes: Task 1's `ci_runs`, Task 2's `tasks.merge_commit`.

**Figure definitions** (each = one private function `(ctx, db, repo string, w metricWindow) (Figure, error)` or its own type; `metricWindow{From, To, PrevFrom, PrevTo, SparkFrom time.Time}` built by `newMetricWindow(from, to)`; every query computes window, previous window, and the 7 spark buckets with one GROUP BY over `(x − SparkFrom)/interval '7 days'`; medians use `percentile_cont(0.5)`):

| Function | Definition |
|---|---|
| `metricDeploys` | count `project_rolls` by `ready_at`; weeks likewise |
| `metricLeadTime` | median of `project_rolls.ready_at − ci_runs.pushed_at` joined `ci_runs.commit = project_rolls.commit` (both `repository = repo`, `project_rolls.commit <> ''`), rolls ready in window; ms |
| `metricCardCycle` | median `finished_at − created_at` of cards done in window; ms |
| `metricThroughput` | count cards done in window |
| `metricChangeFailure` | share of window-done cards with `reverted_at IS NOT NULL`; ratio |
| `metricRevertedRefiled` | of window-done reverted cards: refiled = EXISTS `alerts (task_id = tasks.id, kind = 'alert', raised_at = tasks.reverted_at)`; reverted = the rest; Weeks = reverts per bucket by `reverted_at` |
| `metricTimeToRestore` | median over `alerts (kind='alert', raised_at in window, task's repository = repo)` of earliest `tasks.finished_at − alerts.raised_at` where `tasks.alert_fingerprint = alerts.fingerprint AND tasks.finished_at > alerts.raised_at`; ms |
| `metricSpend` | sum `ledger.eur` joined `tasks on task_id, tasks.repository = repo`, `ledger.day BETWEEN from AND to`; weeks by day |
| `metricPerCard` | median over window-done cards of the card's total `sum(ledger.eur)` (no day filter — what a card costs) |
| `metricTokensPerCard` | sum `audit.prompt_tokens + audit.output_tokens` of the project's card tasks (`ts` in window) / window-done cards |
| `metricModelMix` | shares of `prompt_tokens + output_tokens` by `model_alias` over all the project's calls in window, desc, top 3 then fold into `other`; `Has` = any call |
| `metricInterventions` | count `events (via IN ('button','chat','webhook','console'))` of the project's tasks in window / window-done cards; weeks = ratio per bucket |
| `metricEscalations` | count `alerts (kind='escalation', raised_at in window)` scoped `task_id → tasks.repository = repo` |
| `metricHumanBlocked` | blocked seconds / lifetime seconds over window-done cards; blocked = spans between a `task_status` event whose `detail->>'status'` is `waiting-human` or `waiting-poster` and the next `task_status` event (`lead(at) OVER (PARTITION BY task_id ORDER BY at, id)`), last capped at `finished_at`; approximate by event resolution — comment says so |
| `metricReviewAcceptance` | per window-done card, first `in-review` status event; verdict = the next status event's status: `closing`/`waiting-human` = accepted, `running` = changes asked; share accepted/(accepted+changes) of cards with a verdict; weeks by the in-review event's bucket |
| `metricSelfDeploys` | count `rolls` (the factory's own table, no repository column) by `live_at` |
| `metricDiffSize` | medians of `files`, `insertions`, `deletions` over window-done cards with `files > 0`; Weeks = median files per bucket |
| `metricChatWork` | `chat_messages (repository = repo, role='assistant')`: calls = `sum(jsonb_array_length(tool_calls))`, minutes = `sum((call->>'ms')::numeric/60000)` via `jsonb_array_elements`, `at` in window |
| `metricCIDuration` | median `ci_runs.duration_ms` for `repository = repo`, `pushed_at` in window (endpoint only; the page's deck carries no CI row) |

Zero denominators → ratio 0 with `Has=false`; empty median cohorts → `Has=false`.
