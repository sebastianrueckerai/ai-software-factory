# The writing guide

The writing guide is the body of Sebastian's own writing skill file, copied byte for byte. It lives in the code repository at [internal/writingguide/writing-guide.md](https://github.com/sebastianrueckerai/ai-software-factory-code/blob/main/internal/writingguide/writing-guide.md), and its eight forms live beside it in [internal/writingguide/forms/](https://github.com/sebastianrueckerai/ai-software-factory-code/tree/main/internal/writingguide/forms): chat, line, title, why, summary, brief, ask and finding. Each step whose text a human reads carries the whole guide or the forms of its job, as its profile names them.
