# Market research: who else builds a software factory, and what can we take from them

Started 2026-09-29. Trigger: [future-agi/future-agi](https://github.com/future-agi/future-agi) and the five products it compares itself with (Future AGI, Langfuse, Phoenix, Braintrust, Helicone). Those turned out to be observability tools, so the net was cast wider: every project that resembles one of our five planes or the loop as a whole.

## Files

- [00-our-vision.md](00-our-vision.md): our design on one page. Every report compares against it.
- [01-report-template.md](01-report-template.md): the report shape and the category list.
- [projects/](projects/): one folder per analysed project with a `report.md`.
- [scouting/](scouting/): candidate lists from the scout agents that searched for projects beyond the seed list.
- [SYNTHESIS.md](SYNTHESIS.md): the compiled findings. Market overview, approaches, what we take, where we differ, a shortlist for narrowing. Start here.
- [matrix.md](matrix.md): every report's scores, steal items, differs items and verdicts in one file, generated by [compile.py](compile.py).
- [PROGRESS.md](PROGRESS.md): the working log, with one line per report and the incidents of the run.
- [02-analyst-instructions.md](02-analyst-instructions.md): the instructions every analyst agent followed.

## Method

1. Seed list below, grouped by category, with a tier. Tier 1 projects resemble our whole loop or a plane we care most about and got a stronger analyst model. Tier 2 got a cheaper one.
2. Three scout agents searched the web, GitHub and Hacker News for candidates the seed list missed. Their finds were added as further reports.
3. One analyst agent per project. Each cloned the repository shallowly to `~/repos/market-research-clones/<slug>` (not committed), read code and docs, fetched the website, searched for independent views, and wrote `projects/<slug>/report.md` on the template.
4. The synthesis read every front matter and every report and compiled the findings.

Scores in the reports are relative to our design: 3 means roughly what we do, 5 means clearly better, 0 means absent.
