The gate chain

01

Chat

The project agent files the card. A vague request gets a question first, a large one a split.

intake

02

Spec

The planner drafts the spec. Each criterion gets an id, a kind and a named proof.

the human confirms

03

Plan

Cards filed in dependency order. Validation refuses a plan that leaves a criterion out.

04

Build

An agent works in a sandbox, runs the tests and pushes. The pull request opens.

session

05

Review

Programs run the checks and the named tests. Models review and audit the diff.

checks · policy · reproduction
criteria · review · audit

06

Merge

The project's merge rule: a human approves, or it merges on its own once the gates pass. factory-merge merges.

approval · merge-queue · merge

07

Deploy

The merge rolls staging. Promotion to production is its own step. Done means live.

08

Telemetry

The live change is watched. An alert files the fix card.
