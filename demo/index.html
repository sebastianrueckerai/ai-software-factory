**Row a: Grid with cyan horizon**

Still a3 is the best choice. Its composition is the most stable and cinematic, with a classic perspective grid that converges naturally toward the horizon. This structure will powerfully complement the specified ‘slow drift toward the camera’ motion, creating a sense of infinite, orderly space. It provides a clean, uncluttered field that is ideal for overlaying a white title without distraction.

In contrast, a1’s perspective is slightly less engaging, and a2 has a minor defect: its background is a dark grey rather than the required near-black, which deviates from the specified palette and a looping video model cannot fix a base colour. Still a3 has no defects.

**Row b: Grid with amber pulse**

Still b3 is the strongest candidate. It most effectively interprets the brief’s ‘soft amber pulse crossing.’ The horizontal, scanner-like glow is clean and technological, aligning perfectly with the ‘factory console’ aesthetic. Its soft edges create a sense of energy without being distracting, leaving ample negative space for titles above and below. The motion of the grid drifting through this static pulse will be visually compelling.

A loop cannot fix the core concept of the other stills. Still b1’s pulse is a sharp, directional vector, which feels more like data transmission than a soft pulse. Still b2 is unusable as its background is a distinct grey, violating the ‘near-black field’ palette.

**Row c: Grid with cyan rectangle**

Still c2 is the only viable option. It is the only frame that depicts the ‘thin cyan trace drawing a 16:9 rectangle in the centre’ as a complete, balanced element. Its centered composition creates a clear focal area, acting as a natural frame for a title card or as a ‘monitor’ within the console interface. A looping animation starting and ending on this resolved state would be clean and purposeful.

The loop cannot fix the fundamental defects in the other stills. Still c1 is an incomplete, unbalanced crop of the rectangle. More critically, still c3 depicts a trapezoid, which is the wrong geometric shape entirely and fails the brief’s core requirement for this element.

How to regenerate

demo/run.sh                      # the whole bank
demo/run.sh 01-chat-to-card      # one scene
node --test demo/test/*.test.js  # the tests

A fresh session needs Node 22; Playwright's Node modules at NODE_PATH (default /tmp/claude-1000/pw/node_modules, a path a reboot can wipe; install with npm i playwright in that directory) and Chromium under PLAYWRIGHT_BROWSERS_PATH (default ~/.cache/ms-playwright; npx playwright install chromium); ffmpeg with ffprobe; Go for the lab; and the code repository at CODE_REPO (default /home/womb/repos/ai-software-factory-code).
