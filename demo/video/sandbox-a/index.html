The factory starts one throwaway pod for each card. Before the agent starts, a probe proves the pod cannot reach the internet, the host or the cloud metadata. Every model call goes through the gateway and is held against the card's budget first. The agent never holds a push token or a model key. At the cap, the factory stops and asks you: fund it or end it. When the agent is done, the factory pushes once with a fresh token and deletes the pod.
