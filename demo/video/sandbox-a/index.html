The factory starts one throwaway pod for each card. The pod runs in gVisor, non-root, read-only root, with no service account token. Before the agent starts, the probe tries the internet: blocked. It tries the host machine: blocked. It tries the cloud metadata address: blocked. Only named hosts are open: the repository and registries. Every model call goes through the gateway, which holds the model keys. It meters each call against the card budget: cap €2.00. It reserves the worst case first: €0.30 is held. Then it books the real cost: €0.04. The pod holds a one-hour gateway identity, never a push token or a model key. More calls fill the budget to its cap. The factory stops and asks a person: fund it or end it. When the agent is done, the factory kills it. It mints a fresh write token and pushes once. It revokes the token. And it deletes the pod.
