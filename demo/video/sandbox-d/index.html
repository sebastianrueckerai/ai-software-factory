The factory starts one throwaway pod for each card. Before the agent starts, a probe proves the pod cannot reach the internet, the host or the cloud metadata. Every model call goes through the gateway. It reserves the worst case first, then books the real cost. The agent never holds a push token or a model key. At the card's budget cap, the factory stops and asks a person: fund it or end it. When the agent is done, the factory kills it, pushes once with a fresh token, revokes it and deletes the pod.
