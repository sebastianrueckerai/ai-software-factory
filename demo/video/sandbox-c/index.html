The factory starts one throwaway pod for each card. A write to the root filesystem stops at the pod wall. A call into the host's kernel stops at gVisor. The probe's try at the internet stops at the network policy. Its try at the host machine stops there too. And its try at cloud metadata stops there too. Only named hosts pass the gate. The gateway sits in that gate with the model keys and the card budget. It reserves the worst case first: €0.30 is held. The call goes out; then it books the real cost: €0.04. The agent holds a one-hour gateway identity, never a push token or a model key. More calls fill the budget to its cap. The factory stops and asks a person: fund it or end it. When the agent is done, the factory kills it. It mints a fresh write token and pushes once. It revokes the token. It deletes the pod, and the walls fold away.
